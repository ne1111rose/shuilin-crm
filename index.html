Netlify Drop
最簡單！拖放檔案就完成，完全免費，速度超快
  1. 把 客戶名單管理系統.html 改名為 index.html
  2. 開啟 netlify.com/drop
  3. 把 index.html 拖進去黃色框框
  4. 等幾秒，你的網址就出現了 🎉
前往 Netlify Drop →
🐙
GitHub Pages
免費、穩定、可自訂網址，適合長期使用
  1. 註冊 GitHub 帳號（免費）
  2. 建立新 Repository，命名為 shullin
  3. 上傳 HTML 檔（改名 index.html）
  4. Settings → Pages → 啟用，網址為
    你的帳號.github.io/shullin
前往 GitHub →
☁️
存在 Google 雲端
不需要網址，但可以在任何裝置開啟同一個檔案
  1. 把 HTML 上傳到 Google 雲端硬碟
  2. 右鍵 → 取得連結 → 設為「任何人可看」
  3. 下次開啟：Google 雲端 → 點擊 → 用瀏覽器開啟
  4. ⚠️ 注意：不同裝置的資料是分開的
前往 Google 雲端 →
